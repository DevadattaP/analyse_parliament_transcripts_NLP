About This Project

This system analyzes Indian parliamentary proceedings using Natural Language Processing (NLP) to extract structured information from unstructured transcripts.

The API processes parliamentary session documents (budget speeches, bill introductions, Q&A sessions, debates, ministerial statements) to provide:

  • Speaker identification and role detection
  • Topic modeling and segmentation
  • Named entity recognition (people, places, schemes)
  • Sentiment and stance analysis
  • Automated summarization
  • Interactive visualizations
